SSNE-RECOOP-Native 1.2.8.4 · Multiplayer-Build 267 · Windows x64

Spiel installieren

1. Entpacke das komplette Paket in einen beschreibbaren Ordner, etwa C:\Spiele\SSNE. Verwende einen kurzen Pfad, damit auch vorbereitete Zusatzkarten Platz für ihre Dateinamen haben.
2. Öffne SSNE-RECOOP-Native.exe und wähle deine eigene europäische GameCube-Disc von Serious Sam: Next Encounter (G3BP9G, Revision 0). Das Spiel lässt sich auch aus einer unterstützten Dolphin-RVZ erstellen.
3. Wähle „Install Game“ bzw. „Build Game“. Der Launcher entpackt deine Disc-Daten und erstellt SSNE-Native-Game.exe mit dem Spielsymbol im selben Ordner wie der Launcher. Recompiler und Compiler sind im vollständigen Windows-Paket enthalten.
4. Doppelklicke auf SSNE-Native-Game.exe, um direkt zu spielen. Alternativ kannst du im Launcher auf „Play“ klicken. Den Netzwerk-Multiplayer findest du im Hauptmenü unter „Online“.

Für die Kartenbearbeitung und einen erneuten Build öffnest du SSNE-RECOOP-Native.exe. Behalte den Ordner Multiplayer mit seinen Laufzeitdateien zusammen mit dem Hauptordner.

Mit „Create desktop shortcut to game“ legst du eine Desktop-Verknüpfung an, die das Spiel direkt startet. Bei einer Neuinstallation entsteht sie nach dem erfolgreichen Build.

Die Windows-PAL-Fassung verwendet standardmäßig OpenGL. Öffne im Spiel mit F12 die Einstellungen, wähle unter „Grafik“ beim Renderer „Vulkan (experimentell)“ und starte das Spiel neu. Die Auswahl gilt auch beim Start über die Desktop-Verknüpfung. Der Ordner Vulkan gehört neben die Spiel-EXE und enthält Mesa Zink.

Eine vorhandene Installation aktualisieren

Schließe das Spiel und öffne den Launcher. Bestätige das angebotene Update auf 1.2.8.4. Der Launcher startet dabei neu. Wähle „Update Game“, falls der Launcher anschließend zum Neubau auffordert. Dieser Build verwendet Multiplayer-Protokoll 72. Aktualisiere alle Teilnehmer einer Online-Runde auf dieselbe Version.

Offizielle Mehrspieler-Inhalte der PS2-Fassung

Mit dem standardmäßig gesetzten Häkchen „Include PS2 maps and skins“ richtet „Build Game“ die 15 zusätzlichen Karten, ihre Vorschaubilder, sechs Skins und das Online-Symbol ein. Für eine Installation nur mit GameCube-Inhalten entferne das Häkchen vor dem Build. Du kannst die Auswahl später mit „Update Game“ ändern. Alle Teilnehmer einer gemeinsamen Online-Runde benötigen dieselbe Spielversion und dieselbe PS2-Einstellung.
