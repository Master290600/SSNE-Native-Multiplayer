# Offizielle Mehrspieler-Inhalte der PS2-Fassung

Der Launcher integriert 15 Karten mit Vorschauen, sechs Spielerfiguren und das Online-Symbol beim Bauen aus der eigenen europäischen GameCube-Disc (G3BP9G, Revision 0). Wähle im Launcher **Install Game** oder **Build Game**. Lass das Spiel während des Builds geschlossen.

Die Zusatzdateien liegen im Windows-Startpaket. Der Launcher prüft die Installation. Falls der Vorgang unterbrochen wird, führe **Build Game** erneut aus. Verwende dieselbe Version auf allen Geräten, die zusammen spielen sollen.
