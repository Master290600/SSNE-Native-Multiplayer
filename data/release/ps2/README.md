# Offizielle Mehrspieler-Inhalte der PS2-Fassung

Mit **Include PS2 maps and skins** installiert der Launcher 15 Karten mit Vorschauen, sechs Spielerfiguren und das Online-Symbol. Dafür genügt die eigene europäische GameCube-Disc (G3BP9G, Revision 0). Wenn du nur die GameCube-Inhalte möchtest, entferne das Häkchen. Wähle anschließend **Install Game**, **Build Game** oder **Update Game**. Lass das Spiel während des Builds geschlossen.

Die Zusatzdateien liegen im Windows-Startpaket. Beim Abwählen stellt der Launcher zuvor ersetzte GameCube-Dateien aus den geprüften lokalen Sicherungen wieder her. Falls der Vorgang unterbrochen wird, führe **Build Game** erneut aus. Für gemeinsame Online-Runden wähle auf allen Geräten dieselbe Spielversion und dieselbe PS2-Einstellung.
