# Public test build 203 — version 1.2.7.203

The complete F12 settings menu now follows the selected English, German or
French game language, including its eight tabs, help, choices, Crosshair section
and bot controls. A Game and menu language selector is available at the top.
F12 switches immediately; the original PAL game menus apply an explicit choice
at the next start. Automatic keeps the language from the original game setup.
Language preference is local to settings.ini. Original cards are not rewritten
or deleted to expose the language selector; startup resource preloads are kept.

Crosshair settings, PNG filenames, input bindings and gameplay rules retain their
existing behavior. Protocol 63 is unchanged. See RELEASE-NOTES-202.md for setup
and the multiplayer validation boundary.
